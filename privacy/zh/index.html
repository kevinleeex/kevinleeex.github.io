说明更新 · 2026-11-12

范围

这是李灯举的个人静态网站。新版首页、履历、隐私与赞赏页没有账号、留言表单或本站处理的支付。赞赏页展示本站托管的二维码图片，并提供 PayPal 外部链接；使用任一方式的付款由相应支付服务处理。

本地偏好

页面读取浏览器语言及系统明暗偏好。手动切换时，resume-language 与 resume-theme 保存于浏览器 localStorage，仅用于下次选择语言与外观，不由这些页面发送给站点。可在浏览器的网站数据设置中清除 lidengju.com 的本地数据，恢复自动选择。

访问与托管

新版页面只加载本站脚本、样式、履历图片与二维码，没有添加第三方访问统计或字体。网站由 GitHub Pages 提供静态托管。GitHub 的隐私说明介绍了其服务处理的信息，包括 IP 地址和服务使用信息；具体处理方式以 GitHub 的说明为准。

外部链接与邮件

点击领英、GitHub、专利/论文或 PayPal 链接将访问相应服务，适用其隐私说明。赞赏页的二维码图片由本站提供；只有你打开支付应用识别二维码时，才由该应用处理支付。邮件图标仅在你点击后于本地组装地址并交给邮件客户端撰写，不会自动发送。来信中的联系信息用于回复。无JavaScript时可通过领英或GitHub联系。地址分段只能减少简单源码扫描，不能防止执行JavaScript的爬虫，也不能保证不收到垃圾邮件；历史页面或PDF中的地址可能已经公开。
